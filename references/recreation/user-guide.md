# 独立复刻：对话引导与阶段确认

本参考供Agent在首次使用、初始化、确认CG、配置生成服务或恢复项目时使用。依赖操作见[初始化](initialization.md)，持久状态见[项目格式](project-format.md)，制作与付费边界见[工作流](workflow.md)。通过当前对话引导，不要求管理台、Windows安装包或用户运行命令；后台由 `recreate.py` 与项目 store 保存源清单、角色、版本和接受状态，可选生成适配器单独保存确认与一次性请求 journal。

## 首次进入：先说明路径，再补最少材料

使用者可以直接说“把这个视频中的人物换成动物”“先制作CG预览”或“继续上次的复刻”。不要要求专用命令或内部项目ID。

首次简短说明，按上下文缩短：

> 我会先分析原片、准备本地环境并制作动物CG，供你和原片对照。这个阶段不需要云服务Key，不会上传原片或产生视频生成费用。CG确认后可以直接交付，也可以再选择已开通的模型生成更精细的视频；生成前会说明预算并请你确认。

只询问当前缺少的材料，优先利用已提供的信息：

- 没有原片：请提供视频或本地文件路径。只有图片时说明无法据此复刻完整原动作，不假装已有视频。
- 人物范围不清楚：询问替换哪些人、其他人保留还是移除；先分析原片并提供人物位置说明，帮助选择。
- 动物外观不清楚：询问品种、服装及外观参考；可以给建议，不默认所有项目都是双犬。
- 只要求先看效果：先做覆盖完整动作事件的本地参考，不将“看效果”解释为付费生成许可。

不在首次一次索要预算、模型服务、API Key、存储凭证及所有技术参数。先确认影响当前制作的范围；原音、运镜、场景等已有要求记住，不重复问。计划和事实分开说明，不能将“建议先做代表段”写成“已完成代表段”。

当前已分发犬体仅支持哈士奇 `husky` 和金毛 `golden`，输出是明确标注的屏幕空间 `screen-space-2.5d` 动作参考。其他动物、真实地面/相机/深度恢复、完整手指和脸部重定向仍需另行实现或评估，不能把用户希望的能力写成已经具备。

## 初始化：让使用者知道准备什么

先只读检查工具、内存/磁盘、缓存模型和当前阶段依赖，按需准备；不替用户关闭软件或默认安装GPU后端。仅描述真实检查结果：

| 当前情况 | 使用者看到的说明 | Agent下一步 |
|---|---|---|
| 仅分析原片 | “先检查视频和动作范围，目前无需模型服务或Key。” | 使用inspect最小集合 |
| 本地工具缺失 | 说明缺哪项、用途及准备方式，不抛整段日志 | 只补该项；已授权的常规本地安装不反复请批 |
| 姿态权重未缓存 | 说明固定 WholeBody B ONNX 用于保存身体/手脚脸观测：360242862 字节，来源/许可及 SHA 见初始化 | 先 `model --describe`；可复用显式缓存时用 `model --source` 登记，无缓存且授权下载后才 `model --download-approved` |
| 依赖就绪但权重/动物资产缺失 | “阶段依赖已就绪，还需准备【权重/浏览器/动物资产】才能执行这一步。” | 读取 doctor 的 `dependencies_ready` 与 `execution_ready`，不可将前者当成完整就绪 |
| 资源不足或安装失败 | 说明具体阻塞、可继续的免费工作和一个明确处理办法 | 保留数据，有界修复，不无目标重复安装 |
| 本地条件就绪 | “本地分析条件已具备，接下来提取动作并制作CG预览。” | 检查实际输入后继续，不要求Seedance开通 |

零视频生成费用不等于零下载流量、存储或处理时间。采用实际检查值；未测量时不编造百分比或完成时间。检查、依赖安装和权重下载分开记录，下载完成不代表动作效果通过。

## Agent 后台入口

具体命令和配置由 Agent 填写，使用者只需普通对话。全局 `--runtime-root RUNTIME` 放在子命令之前。

| 阶段 | 实际入口与结果 |
|---|---|
| 看原片、帮助选人 | `recreate.py inspect --source SOURCE --output SELECTION_DIR`，生成本地选择页、首帧和事实清单 |
| 固定角色与源清单 | `recreate.py init --source SOURCE --project PROJECT --roles ROLES_JSON`，可加 `--crop x,y,width,height` |
| 依赖/执行资源检查 | `recreate.py --runtime-root RUNTIME doctor --stage pose` 或 `--stage render` |
| 本地逐阶段执行 | `recreate.py --runtime-root RUNTIME local --project PROJECT`；按缺项执行 track/observe/preview，也可单独调用这些子命令 |
| 纠正角色或锚点 | `recreate.py select --project PROJECT --roles CORRECTED_JSON --confirmation USER_STATEMENT`，旧下游接受失效、候选保留 |
| 查看、接受当前 CG | `recreate.py status --project PROJECT`；人实际接受后 `recreate.py accept --project PROJECT --artifact cg_silent --sha256 EXACT_SHA --confirmation USER_STATEMENT` |
| 可选生成/恢复 | `recreate.py --runtime-root RUNTIME generation ...`，转交[独立生成适配器](generation-adapter.md)的 prepare/approve/upload/submit/status/download/package |

选择、模型登记、接受和恢复均有持久记录；不要直接编辑 `project.json` 或用检测编号猜用户选择。锚点光流只传播平移框；遮挡/交叉等不确定段保留缺测，需新增明确锚点后继续，不假装自动追踪完全正确。

## 制作期间：说明进度和下一步

在项目外部运行目录记录当前阶段、原片/候选版本、已确认范围、已知问题和下一动作。对使用者用自然语言阶段名，内部路径、ID和哈希仅在排错或索要时展开。

进度格式：“已完成【事实】；当前处理【具体事件/问题】；下一步交付【可审阅内容】；目前【未上传/未生成或实际费用状态】。”

每轮修复说明秒点、原因、修改和副作用；有稳定上下文则局部修复。同一机制反复失败且无新证据时，停止试参数，先定位并查成熟方法。保留已有候选和用户接受版本，不静默覆盖。

## CG预览：看哪里、怎样反馈

交付 `review.html`、原片/CG同步 `comparison.mp4`、干净 `cg-silent.mp4`、本地原音版与报告；需要诊断时另做辅助线候选，不把它冒充干净 CG。默认渲染逐帧报告缺失组：低置信躯干、头或肢段会隐藏，不插值、不沿用上一帧、不补造隐藏动作。

原始 WholeBody133 观测完整保存，当前犬体只使用已实现的可见身体与犬体手脸提示，不承诺全指、脸部表情或真实情绪重定向。屏幕空间保留画面中的运动，不分离真实镜头运动与角色世界运动；固定比例与占位场景不能证明真实脚地接触。

先由Agent检查身份、主要动作/节奏、连续性、形体/头颈、接触、构图和场景。表情/嘴部是任务目标时单独复核；不让使用者承担全部排错，不仅凭平滑数值判通过。

> 请先原速看这版【时间段】对照，重点看主要动作和节奏、头身是否自然、脚地关系及画面是否完整。目前已知差异是【清单；没有则说明已检查范围】。可以回复“这版CG可以作为生成参考”，或指出“几秒、哪个角色、什么现象”；也可以只保留CG。

记录确认的具体CG及时间范围。接受CG不代表最终效果接受、原片上传许可或付费授权；局部接受不外推全片。“继续”按阶段和已有授权解释，可以继续免费修正，不能据此越过未完成的CG或付费确认。

## 可选精细视频：先选输出，再配置服务

生成方案的动作保留/自然适配范围及提示词按[自然化经验与模板](generation-guidance.md)准备。向使用者说明哪些必须保留、哪些可调整，不把提示词模板当效果保证。

CG确认后提示“交付CG”或“用视频模型生成更精细的动物视频”。后者不是导出高精度3D网格或可编辑模型；用户说“高模”时结合上下文说明交付物，必要时澄清。

需要生成时，核对实际账号/区域已开通且支持本次输入的型号；无法只读核实时询问使用者并标明未核验。展示候选差异及预算，不默认2.5/Mini，不用付费POST探测开通状态；按[模型选择与预算确认](workflow.md#可选seedance生成模型选择与预算确认)执行。

| 需求 | 引导内容 | 凭证与边界 |
|---|---|---|
| 只做CG | “无需开通云服务，直接交付本地结果。” | 无云服务Key |
| 已选兼容Seedance | 核对型号开通、区域和费用，说明生成/查询用途 | 该账号的`ARK_API_KEY`；Key存在不证明型号已开通 |
| 适配器使用TOS传CG | 说明纯CG需传私有对象存储供模型读取，检查已有桶/区域和必要权限 | `VOLC_AK`、`VOLC_SK`、`TOS_BUCKET`及实际区域/端点；存储/请求/流量可能另计费。TOS是该实现依赖，不是本地CG或所有上传实现必需 |
| 已有安全 HTTPS CG 引用 | 说明会读取模型实际引用的全部字节，验证与当前 CG 的 SHA 相同 | 不需要 TOS SDK/存储凭证；仍需本轮上传/购买确认，不能仅信 URL 名称 |
| 不在已实现 profile 中 | 说明当前型号或规格未支持，可保留CG | 不猜参数、不付费探测、不启动旧管线或自动换型号 |
| 未开通/余额受限 | 展示实际错误和所选服务处理入口，区分开通预留门槛与样片费用 | 不擅自充值、购买套餐或开通其他型号；使用者处理后核实恢复 |

凭证仅在需要时引导：优先使用使用者明确指定的已有凭证来源；没有时引导保存在Skill目录外的私有本地配置，读取验证仅报告“已配置/缺失/验证失败”。不要求将密钥粘贴到聊天，不在日志、预览、分发包或报告展示密钥/签名URL；不复制整份旧管线配置，不引导进入管理台。账号开通、充值由使用者处理或另行明确授权，安装依赖许可不等于账号操作许可。

本地原音回装不需要ASR/TTS/其他LLM服务。新增配音、自动语义分析或其他云功能时另说明用途、依赖和预算，不偷偷增加必需Key。

生成前展示并确认：确切型号、参考/输出范围、时长/分辨率、声音、次数、单次/本轮费用、预算上限、定价依据、额外费用和返修范围。素材及请求准备好、CG范围确认和本次模型/预算确认齐备后才上传/提交。当前上下文已完整确认同一方案则不重复询问；换模型、素材或新增次数重新说明变化并确认。

`prepare` 先完成本地冻结，用户审阅后才 `approve`，再上传/提交。TOS 模式仅在需要时准备 `generate-tos`；上传前先检查 SDK，缺依赖不占用 PUT 次数。此版本云端状态/传输已做离线 fake transport 回归，尚未实测真实账号、TOS、计费或生成质量，不能据此声称已跑通供应商。

## 生成、交付和恢复

- 生成中：只报告实际状态；结果未知先查原任务，说明“正在核对”，不直接再买一次。
- 生成后：下载保留 `model-original.bin` 原始字节与真实逐帧 probe；自动本地生成原音版、原片同步对照和审阅页，分别说明模型实际覆盖与共同对比窗口，不循环、冻结或变速凑时长。包装失败仍保留原生结果，可用 `generation package PROJECT RUN` 纯本地重做。
- 效果确认：请使用者看原速完整事件。生成完成、技术校验、用户效果接受分别记录；失败不自动付费返修。
- 全片：明确范围、接缝和剩余预算；小样接受不等于全片完成。已接受方案保留为本项目基准，不自动外推其他原片。
- 继续/更新Skill：先读项目阶段、最后确认和已有远端任务，简短说明“上次到哪里、本次接着做什么”；配置/缓存保留，不重复索要材料，不复用已消耗的一次授权，不以重新POST恢复。

引导验收应覆盖：新用户无Key进入本地检查；缺权重只补指定文件；CG不接受留在免费修正；只要CG不触发云配置；生成前可见型号/预算；TOS缺配置单独说明；更新后读回旧项目；结果未知不重复提交。对话约定及分发检查不等于上述场景已在新机器端到端跑通，报告实际验证范围。
