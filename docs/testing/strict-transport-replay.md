# 严格传输回放：客户端验证切片

当前实现位于 `tests/strict_replay_support.py`，用于单进程、串行运行真实 Provider 客户端。它是 M1 的前置测试设施，尚未接入 Flow Guard Full，也不代表完整生产 handler 或 Worker 已通过。

## 运行

在项目根目录使用已安装的 Python 环境：

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_strict_provider_boundary -v
```

不需要 Provider 凭证。测试临时替换环境变量中的凭证为固定假值，退出时恢复；不会修改 `.env`。ASR 输入、下载文件均在临时目录，测试不读取或修改正式任务数据库。

## 替换边界

保留正式 Seedance、豆包、ASR 客户端的请求构造、响应解析、轮询、下载校验和回调。替换 HTTPX 默认同步/异步 transport 的请求执行，以及测试中的轮询等待；ASR 测试固定 UUID 随机源以核对提交和查询的任务关联，不替换客户端业务方法，不调用高层生成 handler 夹具。

`tests/fixtures/strict_transport/*.json` 是人工编写的接口契约样本，不是线上录制，也不是识别金标。请求方法、完整 URL、JSON 或非 JSON 请求体摘要必须与固定样本逐项匹配；当前请求不能反向生成“预期请求”。新增或漏掉请求、吞掉边界异常，都会让测试失败。

每一步显式声明 `request.headers`，核对鉴权、资源和任务关联等协议字段；`null` 表示该请求头必须不存在，用于检查媒体下载不携带鉴权。未声明的 HTTPX 默认头不参与匹配。ASR 请求 ID 是独立固定的测试常量，缺失或在查询阶段变更都会失败。

样本保存明确的 `fixture_id` 和 `source_kind=authored_contract`。运行记录只包含请求摘要和请求头名称，不记录凭证值或原始提示词。HTTP 响应、业务错误和传输错误必须显式列入样本，不允许回退在线调用。

## 已覆盖与未覆盖

| 检查 | 本切片验证的行为 | 仍未证明 |
|---|---|---|
| Seedance 正常返回 | 提交、运行中轮询、完成轮询、下载、回调 | 真实模型生成或可用视频 |
| 不确定提交 | 无任务 ID 时停止，不追加提交 | 管理台恢复按钮、跨进程幂等 |
| 轮询与下载异常 | 沿用原任务 ID，下载失败保留恢复信息 | Worker 重启后恢复成功 |
| 下载重定向 | 分别拒绝非 HTTPS 与私有地址 | 任意网络栈的安全性 |
| 豆包 | 实际请求体、JSON 响应和 usage 解析；截断 JSON 失败 | 来源至简报/剧本的完整服务流程 |
| ASR | 实际提交、轮询、说话人/情绪字段解析；拒绝响应不当成功 | 音视频识别准确率、表演还原 |
| 隔离护栏 | 拒绝标准 socket 发送、DNS 和 Python 进程启动入口 | OS 沙箱、原生扩展、完整进程树隔离 |

下载样本使用不可作为视频解码的合成字节，ASR 输入同样只用于传输契约。不得用这些文件声明媒体技术质量或内容质量通过。

## 使用限制与后续接入门槛

1. 该工具修改当前进程的 transport、环境和标准网络/进程入口，只能在独立测试进程内串行使用，不得嵌入管理服务或并发业务线程。
2. 单次上下文不可重复或嵌套使用。退出时恢复补丁；失败不能因为业务代码捕获异常而变为通过。
3. `process_tree_verified` 和 `content_quality_verified` 固定为 `false`。`scope=in_process_http_transport` 不升级为端到端证明。
4. 下一步需将固定响应接入真实生产 handler、临时数据库和真实本地媒体处理，再完成管理 API、浏览器与 Worker 进程树的隔离和故障恢复测试。
5. 接入后仍需独立验证非零模拟成本下的预算占用、幂等、旧任务结果复用，不能用“实际费用为零”跳过付费工作规则。
6. 在上述完整旅程完成前，Flow Guard 的 `strict_transport_replay` 仍为 `not_run`。参见 [测试证据边界](assurance-boundaries.md)。

## 正式处理器接入清单（未完成）

首条旅程以人物锚点为最小单元：真实图节点领取 → 正式 handler → Seedance 传输回放 → 本地抽帧 → 待人工审核。成功条件是生成了可检查的临时资产并进入真实审核状态，而不是调用到生成函数或预先写入 `OK`。

| 边界 | 必须保留的生产逻辑 | 接入要求 |
|---|---|---|
| 冻结图与调度 | `run_graph_job`、节点租约、`build_handlers`、冻结规格读取 | 使用临时文件 SQLite，不能把正式任务或内存库连接意外替换成默认库 |
| Seedance | 请求构造、任务关联回调、轮询、下载 | 固定契约返回可解码的媒体字节，摘要独立记录；损坏下载仍应失败 |
| TOS | 签名、HEAD/上传处理及结果解析 | 在 SDK 使用的 Requests `HTTPAdapter.send` 替换传输，不替换 `tos.upload` |
| 本地媒体 | FFmpeg/ffprobe 的真实处理与文件检查 | 仅访问隔离输入输出；不能因当前客户端护栏禁止子进程就把媒体处理也 mock 掉 |
| 成本与审核 | 占用、结算、候选状态、人工确认和恢复 | 模拟账本仍记录非零成本；确认前暂停；重入和重启不得重新购买已完成资产 |

人物锚点本身不要求语音 QA，不能将该旅程的通过算作 ASR/台词/母片 QA 覆盖。后续母片旅程需分别回放这些配置所要求的外部响应，并验证缺台词、质量不通过和候选接受分支。

禁止把整个 handler 直接包在当前 `StrictTransportReplay` 中：它会清理数据库配置且禁止本地子进程。需要先完成临时路径固定、传输覆盖和本地工具隔离，再执行正式处理器。单进程护栏不能宣称完整进程树已隔离。
