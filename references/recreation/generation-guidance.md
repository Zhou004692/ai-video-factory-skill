# CG转动物视频：动作自然化经验与提示词

在CG预览确认后、准备可选视频生成请求时读取。先遵守[模型选择和预算确认](workflow.md#可选seedance生成模型选择与预算确认)，本参考不提供调用授权或通用提交适配器。

## 证据范围

2026-10-20的一次Seedance 2.5双犬舞蹈候选采用“保留主要编舞、允许局部动作自然化”的提示，用户明确反馈“这个效果可以了”。参考段为8秒，实际模型输出约7.71秒、720p；接受范围仅为该小样。它支持将该策略作为后续候选起点，不证明某一句提示词的因果效果、每次稳定成功、完整原片通过或对白拟人情绪已经解决。没有严格控制变量的同输入多次实验，不能将效果差异全部归因于提示词。

Mini准备版仅将秒点表述换成动作阶段描述；当次因模型未开通被明确拒绝，未获得Mini输出。因此本模板未验证Mini效果，也不能宣称更便宜型号效果等同。模板是从单项目提炼的指导，具体模型能力、参数与价格仍在执行时核查；不把本项目人数、犬种、秒点或预算当作默认值。

## 先决定哪些保留、哪些可调整

| 层次 | 应写清的内容 | 边界 |
|---|---|---|
| 必须保留 | 角色映射、主要动作及先后、关键节拍、方向、相对走位、约定场景/物件关系、镜头意图和构图 | 是本次验收目标，提示词本身不保证实现 |
| 允许自然化 | 局部关节、摆爪弧线、步幅、落脚、适度骨盆起伏、胸肩跟随、头颈与身体协同 | 先取得用户对适配范围的同意，不能借此改舞、改角色或删掉关键动作 |
| 不作为精确目标 | 已确认的CG细小抖动、直杆姿态、不合理接触高度 | 只排除已理解的参考缺陷，不把未知深度或合理滑移/腾空误判为错误 |

发现主要动作缺失、身份切换、严重断肢/穿插或场景几何混乱时，先回CG定位原因。不要把一切问题交给生成模型猜。若用户要求严格动作轨迹，应先解释自然适配的取舍，不能擅自放宽。

## 按完整事件描述修复

选一个有清晰上下文、足以观察起势—动作—承重/反应—收势的事件。注明源时钟、提交片段内位置、角色、保留项及允许改变项，避免把原片14秒错写为裁切小样14秒。

- 描述“躯干/骨盆如何带动，肩髋膝爪如何跟随，重量如何转移，怎样接回下一步”，比只堆“真实、自然、不要飘”更具体。
- 秒点仅在选定型号明确支持且实际请求验证过时使用，同时给动作语义定位；否则按“抬腿后第一次转身换步”等可辨事件描述。不要从一个型号的提示方式外推所有型号。
- 保留原动作的转脚、移动接触、滑移和真实腾空，不用“全程锁脚、每帧贴地”代替承重。源片看不清的状态明确是允许的补全，不伪造源事实。
- 稳定头颈应同时描述颅底连接、颈长、头部大小和胸肩跟随；侧身/背向允许自然离开正脸，不同时要求固定朝向镜头。
- 生成模型不是确定性局部修复器。即使只写一个角色/事件，其余身体、角色、镜头和画面也必须重新检查。

## 提示词模板

先替换所有方括号，删除不适用的句子。素材编号按真实content顺序编排；图片只约束外观、CG约束动作与空间。无身份图或无视频时不能留下虚假引用。动作与场景描述来自本次已确认清单，不照抄旧舞室。

```text
编辑[实际视频引用]，将[参考角色及映射]制作为[目标动物、外观风格和服装]。
[实际图片引用及各自角色]只定义[品种、毛色、耳型、脸型等]，不继承图中的姿态、道具、背景或景别。

视频提供主要动作：保留[事件顺序、关键节拍、可辨认动作幅度、方向、角色相对走位和镜头意图]。
在上述范围内，允许按目标身体比例调整[本次已同意的关节、步幅、落脚、骨盆起伏、胸肩跟随等]。
[已定位的CG缺陷]不作为逐帧复刻目标；不要通过放慢、删减关键动作、缩小幅度或强运动模糊掩盖问题。

重点自然化[明确角色和事件定位]：保留[动作含义、转向过程及节奏]。
把该事件作为连续动作组织：[起势与驱动部位]→[身体/关节跟随]→[承重转移或其他反应]→[自然接回下一动作]。
允许[具体局部调整]，不强行贴合[已理解的不合理参考数值/形态]。事件前后连续，不在窗口边界突变。

保持[本次场景、物件、地面及角色交互关系]；有接触时承重可信，合理保留原动作的转脚、移动、滑移和腾空。
体型与肢体长度一致，遮挡前后连接连续；头颈与胸肩协调，保持头部大小和颅底连接，侧背身可自然转离镜头。

保留[场景布局、材质/灯光、物件位置、遮挡关系和运镜]。
输出[已约定构图]，为[耳尖、足爪和动作极值]留余量，不额外推近、切镜或改变动作。
[情绪事件与强弱要求；没有此目标则不堆表情指令]。
[本次声音、文字及辅助线要求；与实际请求参数一致]。
```

不要将这段文字当API请求：`edit`模式、时长、音频和格式等须由本次型号的适配器正确编译。文字写“静音”不能替代对应请求参数。复杂长片先选完整代表事件，不按固定秒数机械切分。

## 常见反模式

| 反模式 | 修正 |
|---|---|
| “每帧一模一样”与“自行修好关节”同时出现 | 分别列出必保留与可适配项，消除互相冲突的要求 |
| 只加“自然、不飘、不闪”继续付费试 | 先定位具体事件和错误层，说明本次改变什么、怎样判断收益及副作用 |
| 全程锁脚、统一正脸 | 区分支撑/转脚/腾空；保持头身协同，允许符合动作的侧背身 |
| 身份图含人手、道具或错误姿态 | 准备合适身份图，明确素材职责，核对提交媒体而非只看文件名 |
| 交替表情图插值、放大张嘴当拟人情绪 | 按注意—反应—情绪增强—收敛描述事件，眼神/眉区/嘴角/头身共同表现；自然感染力仍须实测 |
| 用辅助线或占位阴影假装恢复真实地面 | 诊断版与提交版分开；承重和场景仍按输出验证 |
| 原片30fps与输出24fps直接按同帧号比 | 按实际时间/PTS比较，保留原生文件，不冻结/循环/变速补齐 |

## 生成后的验证闭环

1. 先验完整事件的主要动作顺序、幅度与节拍，再看自然度、头身、脚地、碰撞和构图；不能只挑静态好帧。
2. 对模型原片、CG和原片按同一时间对照，明确实际共同窗口。音轨回装单独检查，不将封装时长误认为生成帧覆盖。
3. 报告本次保留了什么、哪里自然化、哪里新增偏差，以及哪些是用户接受而非测量保证。小样接受不外推全片或新源。
4. 失败时先给可解释的修复选路；新增模型调用仍须按型号和预算确认，不自动返修或换seed重复购买。
