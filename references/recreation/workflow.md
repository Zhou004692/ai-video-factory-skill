# 独立原片复刻：动作、情绪与场景

适用于给定原片、替换人物为动物或其他角色，保留动作与场景关系。它是Agent操作的独立工作流，不调用原管理台的来源、Brief、剧本审批、母片生产、发布或业务数据库。先按[初始化](initialization.md)准备当前阶段的最小依赖。

## 明确目标与路线

先看真实原片，冻结本地SHA、视频尺寸、有效画面裁切、帧数/帧率/时间戳、原音和目标时长。用`scripts/recreation/inspect_media.py`得到事实；它不自动决定裁切，也不保证VFR源帧映射。抽取首尾、转身、遮挡、交叉、抬腿、镜头运动等代表帧，保留源帧号和时间。

将用户要求写成项目契约：

- 哪些人物参与、各自对应什么动物、其余人物保留还是移除；人数、品种、服装遵从本次要求，不硬编码两犬。
- 动作与节奏的必保留项；表情可不一比一，但要迁移情绪、反应和强弱，避免只有动物本能表情。
- 场景、道具、空间位置、镜头和原音的保留项；输出是CG参考还是写实生成成片。
- 当前允许的免费分析/本地处理、模型下载、源片上传、付费生成范围和预算。

常见路线分开评估：有资格的视频参考可直接检验Seedance能力；当前不能提交原片时，可先离线提取动作并制作纯CG参考，再评估后续编辑。CG路线是可检查的控制候选，并非已证明能让生成模型精确保留全部动作与表情。不要为了供应商门禁伪装素材类型、误称已获授权或隐藏仍含真人的图像。

免费本地分析不依赖供应商人物素材ID；供应商资产资格在实际准备上传/提交相关素材时核查，不能用付费提交的前置条件阻断可独立完成的离线工作。

用户指定模型路线优先；当前默认使用RTMPose。换姿态模型之前先确认故障层，不能把身份切换、相机、rig和拟合问题都归因于模型精度。

## 本地执行与阶段验收

| 层 | 做什么 | 通过依据与易错点 |
|---|---|---|
| 身份 | 明确每个角色的源人物，检查首尾及所有遮挡/交叉过渡；困难区间连续核查 | 检测候选编号不是稳定人物ID；锚点可能选了不同人。先修身份，再处理抖动 |
| 观测 | 保存原始关键点、置信度、bbox、schema与模型版本；标记可见/遮挡/画外/不确定 | 高confidence不证明可见或归属正确。画外脚点、落衣服上的眼点、其他人的腿不能直接成为强约束 |
| 裁决 | 对同帧同身份的独立候选结合原图与时序审查，写裁决ledger | 保留原始数据；不比较不同模型confidence大小，不逐帧硬切/简单平均；被遮挡姿态标为估计 |
| 三维拟合 | 骨长固定、关节映射正确，连续拟合可见投影及有依据的深度；保留稳定上下文 | 含突跳的先验速度会把错误带回。直接检查运动导数、膝弯曲平面与深度分支；不靠全片平滑掩盖错误 |
| 重定向 | 对动物比例绑定头颈、躯干、四肢、足爪，保持刚性形状与连接 | 人体骨架准确不代表犬体适配正确；检查实际网格而非仅骨架。足爪方向用可见跟趾候选，缺失时处理角度环绕，不能任意转整圈 |
| 相机场景 | 区分人物根运动与镜头运动，恢复共享坐标；列出场景/道具及交互 | 各人物分别归原点后拼接会破坏位置。逆补偿防双重移动；2D/2.5D近似、固定深度层和占位地面须明确，不能冒充物理脚底支撑 |
| 表演 | 动作保持原片；眼神、眉眼、口部、头部反应共同表达源情绪 | 情绪靠完整事件与自然过渡，不能只把笑容/张嘴推大，不能把连续图片插值或脸部渐变当表情复刻 |
| 渲染导出 | 原源帧一一对应实际CG帧，局部修改保留旧帧与原音，生成可定位对照 | 记录新渲染与复用数量；全媒体解码、帧数/时长/音轨和哈希验证。不得循环、慢放或丢帧凑时长 |

初次先交付足以观察完整动作事件的参考段；长度依动作周期决定，不固守2秒或8秒。用户要全片时覆盖全部源帧，检查新增首尾，不能把中间小样正确外推到全片。

## 闪现/抖动的修复顺序

从用户指出的秒点向前后扩展连续区间，按“原片 → 身份 → 观测 → 拟合 → 实际网格 → 编码”定位第一处偏差。

1. 验证人物是否切换，源帧是否错位，裁切/缩放/坐标原点是否一致。独立源图对照不可沿用同一错误偏移作抵消校验。
2. 看异常点在图中是否真实可见、属于目标人物。拒绝/降权不可靠点，不覆盖原观测；需要补采时只对确切源帧重推同路线模型。
3. 检查深度分支、左右腿归属、膝弯曲平面、足爪角度展开、头部范围与骨骼绑定；局部修改保留稳定上下文和接缝。
4. 同时核对动作峰值时间、运动幅度、支撑/腾空和左右关系。速度/加速度变小只证明更平稳，可能已经损失动作；不得单靠指标改善判通过。
5. 实际渲染故障区间并复现旧故障作为负向控制。验证未修改角色/身体部位、后续帧、镜头和旧文件保持。修复后生成新候选，不替换用户已接受的历史产物。

不要把本次已知秒点、角度阈值、裁切、人物数量或遮挡区间固化为新原片的通用规则。每个原片需重新观察和建立契约。

## 场景、物件、接触与生成衔接

场景清单应覆盖可见背景布局、材质/灯光、物体形状与位置、角色接触对象、遮挡前后关系、镜头运动；提示词和CG均引用同一清单。占位CG不能证明Seedance会准确还原细节。

脚底、手爪、脸/胸腹、道具接触分别检查实际表面；排除有依据的关节连接重叠，保留碰撞候选及未覆盖项。物理地面或支撑标签尚未建立时，不逐帧把最低脚压地或用阴影掩饰悬浮。静态碰撞检查不能替代运动/体积穿模验收。

需要Seedance时独立确认供应商当前参考/编辑约束、素材资格、时长/分辨率、预算与一次提交范围；只读取相关provider参考，不能因此初始化旧制作管线。此子功能尚未提供独立付费提交适配器，不冒用原管线任务；先完成真实可审阅的输入、提示词与请求预览，授权后再选择并验证适配器。保留动作/场景的提示词不能视作能力保证，交付必须对实际输出逐项验收。没有付费许可时停在免费参考交付，不自动换供应商、上传或重试。

## 交付与结论

交付原片/候选同步对照、独立CG或生成结果、可逐帧/原速/半速审阅入口、修改说明和证据。分别报告：

- **数据与工程回归**：身份/作用域/骨长/源帧时序/实际网格与渲染记录/导出完整性。
- **复刻保真**：动作幅度与相位、情绪表达、镜头与场景/道具关系、支撑和接触。
- **用户观感**：是否自然、有感染力、是否接受当前候选。用户未答不等于验收通过。

只通过第一类时可以交付排错候选，不能宣布最终目标达成。明确仍估计的遮挡深度、弱相机区间、幅度折损和未通过接触。按“秒点—原因—局部修改—前后对照—副作用”留下可复用记录，避免盲试参数或重复付费。

## 成熟方法参考的使用边界

优先检索一手实现/论文，明确其解决的层、适用条件、输入输出、许可与本机可行性，再决定是否采用。以下是方法导航，不是已安装能力：

- [RTMPose / RTMLib](https://github.com/Tau-J/rtmlib)：姿态观测；不单独解决稳定身份、相机或物理接触。
- [ByteTrack](https://github.com/FoundationVision/ByteTrack)：跨检测关联的参考；离线锚点路径关联不能声称复现完整ByteTrack。
- [HuMoR](https://geometry.stanford.edu/projects/humor/)：鲁棒时序运动先验/部分观测拟合；本地固定骨长连续拟合不等于已运行其学习模型。
- [UnderPressure](https://github.com/InterDigitalInc/UnderPressure)：接触判断与后续IK的参考；低速/高度阈值并非普遍可靠标签。
- [OpenCV平面映射](https://docs.opencv.org/4.x/d9/dab/tutorial_homography.html)：背景平面运动；不是完整度量三维场景与相机恢复。
