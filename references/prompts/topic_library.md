# 题材库:工程设备租赁行业(高机 / 叉车 / 挖机 / 装载机)

> 本文件是 s1 LLM 写 storyboard 时的**创意素材库**——给 LLM 提供"行业真实梗点 + 短视频热点模板",而非直接生成内容。

## C. 组合用法(LLM 在 s1 阶段照这套路)

```
Step 1: 从 A 表挑 1-3 个真实梗点 → 写进 reversal_research[]
Step 2: 从 B 表挑 1 个模板 → 决定分镜结构
Step 3: 把 A 的具体数字 / 规则 / 后果,套进 B 的分镜模板,生成 5-6 个 shots
Step 4: reversal_picked 字段写明"用 A#X + B#Y"
```

**示例**:`A#10(事故修补车)` + `B#1(反差打脸)` = J-VERIFY04 已跑通的剧本结构。
