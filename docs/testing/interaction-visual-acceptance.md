# 交互与视觉优化验收（3.2.0.8）

实施基线为 main `cc094d7` / 3.2.0.7，工作分支为 `feat/interaction-visual-20261013`。方案与任务对照见 [实施计划](../superpowers/plans/2026-10-13-interaction-visual-optimization.md)。本记录说明交付行为与证明范围；最终 HEAD、测试结果、截图和实际 ZIP 摘要由本次发布证据单独记录，不以较早候选替代。

## 工作区和状态

内容工作区按来源、简报、剧本、制作、审核和发布定位，待办按独立决策计数。计划完成、母片完成、活动队列/租约/远端受理分别展示。仅规划的 PENDING 不显示为活动；无执行证据的旧状态保守显示待核实。后端投影给出合法动作、阻塞原因及定位，旧 API 动作字段保持兼容。

1920/1440 保留多栏，1366/1280 默认收起检查栏，1024 使用项目抽屉；小于 1024 显示桌面窗口提示。关键操作正文至少 14px、辅助信息 12px。八类页面统一按钮、表单、状态、加载、空状态与错误反馈。

## 内容修改和制作确认

来源、简报和剧本按具体对象编辑。画面人物与声音说话人分别展示，旁白不新增实体角色。修改影响展示受影响场次、人物、时长、制作准备、预算及审核。保存/批准使用看到的 revision 或分析摘要；发生冲突保留输入和服务端差异，不能覆盖新版本。

制作设置按人物、场景、声音、输出、预算分组，底部固定费用和操作。保存设置与离线编译分开，编译返回的规格与费用来自同一快照；提交生成再次核对规格 hash。原生修复的准备与真正付费确认分开，采用现有来源身份和单次预算合同。

## 等待、失联和恢复

普通 JSON 查询等待上限 15 秒，变更请求 60 秒；2 秒出现等待说明。上传单独提供等待期限和中断提示。切换对象或关闭工作区使迟到读取失效。

付费生成或外部投稿在发送前保存随机命令 ID、路径及原始 UTF-8 请求体 SHA256；不保存请求正文、密钥或附件。刷新后恢复这条身份，不自动重发。服务端在业务处理前绑定身份、在写回浏览器前记录结果。同一 ID 重放返回已记录结果，不再次处理业务；换请求正文或路径会拒绝。

结果未知时，在制作弹层、投稿抽屉或全局提示中核对 `/api/commands/<id>`。只有 ID、路径、摘要完全匹配的已知结果解除阻止。未找到受理记录时，可明确取消未受理请求；服务端原子记录取消结果，此后到达的原请求被拒绝。已经受理的工作不被这个动作中断。核对为只读操作，不新建供应商任务。

未保存修改通过继续编辑、保留草稿、放弃修改处理；草稿按对象和版本隔离，只保存非敏感字段。弹层维持焦点、背景 inert、媒体原生键盘操作及关闭后返回焦点。提交失败保留字段和播放位置，任务浮层不遮挡固定操作区。

终态 500 的原始未知结果不会被删除或改写。请求进程中断后，仅当原归属进程已确认结束，或本进程内的请求确已退出，才将无结果的请求显示为可人工核对；活跃请求保持等待，无法证明归属进程结束时保守处理。需要人工核对时，填写该请求的结论、说明及依据并明确确认，再追加核对记录。存在活动生产或不确定远端记录时，不能将请求声明为未执行。人工结论不会把任务、候选或渠道标记为成功，原请求仍禁止重放，后续操作继续遵守生产和供应商账本门禁。

## 审核、修复及发布

内容与成片审核同屏显示播放器和检查依据。有效证据区间可定位播放；无效区间和无法播放的素材不冒充验证完成。正式成片六项质量需逐项确认，取消一键全部通过。接受候选与成片审核必须绑定看到的文件 SHA；缺少候选身份不能接受。

本地重剪先预览后选择是否采用；原生编辑/延长先说明范围、来源和费用，再显式确认。已有素材、候选和费用保留；替换素材后按既有管线重新检查内容与合成保留。

发布区分别展示待投稿、平台审核、拒绝、已核实发布、人工登记和历史未核实。实际成片与创作意图保持不可变关联。绩效记录展示观察时间、来源及历史快照，未知值保持 null。

## 验证入口和边界

项目页导航开始即禁用上一次主动作并移除旧处理器；加载期间点击旧阶段或大纲也不能重新启用操作，最新查询完成后才重新绑定当前阶段动作。查询失败保留内容并提供重试，不恢复过期操作。切换项目或阶段后，原导航回调根据序号、项目和阶段拒绝覆盖新选择。浏览器旅程等待当前任务关联的项目、阶段及主动作就绪，不能把页面外壳已出现视作数据加载完成。受控等待响应的回归检查验证此边界。

- `tests/test_management_http_concurrency.py`：真实 HTTP 慢媒体、外部核对、冷 SHA、鉴权及命令身份边界。
- `tests/test_production_presentation.py`：活动、门禁、待办、旧状态和只读不变更。
- `tests/interaction_visual_browser_check.py --work-root <临时目录> --batch all`：六视口、八页面、焦点、草稿、错误、设置和审核；提交由浏览器隔离路由明确拒绝，不能作为实际命令受理证据。
- `tests/management_command_browser_check.py --work-root <新临时目录>`：真实本地命令取消、迟到原请求拒绝、等待中刷新恢复，业务状态保持不变。
- `tests/creative_delivery_browser_check.py --work-root <新临时目录>`：真实 HTTP 受理后丢弃浏览器响应，找回命令结果；实际 Worker、FFmpeg、本地重剪、重启、审核和发布反馈使用合成高层 provider。
- 全量 unittest、零费用 R0–R4、Skill 更新门禁及 `skill_delivery_journey.py --legacy-ref cc094d7 --legacy-expected-version 3.2.0.7 --wheelhouse <离线目录> --work-root <新临时目录>` 分别保留最终日志和结果。

测试只使用临时运行目录、随机回环端口和无凭据环境；正式端口 8765、用户数据库、供应商任务和费用不作为测试对象。截图须通过 UU 远程桌面隐私检查，只采集隔离本地页面。真实 ZIP 测试检查全部生产资源的字节、摘要和 MIME，并验证缺失资源不返回 HTML。

这些检查不证明 Seedance/ASR 真实识别效果、人物/空间连续性质量或平台实际投稿成功。Flow Guard 原有 partial 范围保持；后续真实效果验证需单独选择小样本、明确预算与验收内容。本次未自行更新 main、推送或重启正式服务。
