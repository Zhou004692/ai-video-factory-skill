# 生产模型与实测成本

## 主生产模型

当前生产流只使用 `doubao-seedance-2-5-260628` 生成原生母片。Seedance 2.5 一次生成画面、中文人声、环境音和口型；成片通过 FFmpeg 从 2—3 条母片本地剪出 4—8 个段落，不再串联 TTS、OmniHuman 或第三方口型模型。

| 场景 | 请求方式 | 作用 |
|---|---|---|
| 首个真人口播镜头 | 纯提示词 | 建立虚构人物、原生声线和当前场景 |
| 同人物后续真人镜头 | `reference_video` | 稳定人物身份；不再叠加音频引用 |
| 同人物无人脸画外音 | `reference_audio` | 稳定原生声线，同时避免人物出现在 B-roll |
| 独立 B-roll / 环境镜头 | 纯提示词 | 不需要人物或声线延续时减少参考成本 |

## 真人资产发现

固定真人角色先使用火山方舟 Assets API 查询账号内资产，不读取浏览器或控制台页面。接口使用 `ark / 2024-01-01`，只检索 `GroupType=LivenessFace` 且 `Status=Active` 的资产。角色名精确且唯一时，本地保存 `asset://<assetId>`；API 无权限、无结果或多结果时，由 Agent 只向用户索要 `assetId`，再完成本地绑定。真人资产的创建与授权仍由用户在火山控制台完成。

## 计价口径

任务完成后以响应中的 `usage.completion_tokens` 为准，当前实测单价为人民币 `¥0.07 / 1,000 completion tokens`。费用必须按 provider 调用逐笔累计；被质检拒绝、超时后完成、整镜重试等调用也是真实成本，不能只按最终成片估算。

| 实测场景 | completion tokens | 成本 |
|---|---:|---:|
| 6 秒，纯提示词 / 音频引用 | 58,045 | ¥4.06 |
| 6 秒，视频引用 | 115,690 | ¥8.10 |
| 18 秒，纯提示词 | 173,335 | ¥12.13 |
| 24 秒，纯提示词 | 230,980 | ¥16.17 |
| 30 秒，纯提示词 | 288,625 | ¥20.20 |

参考素材会影响 token 数：视频引用约为同长度纯提示词或音频引用的两倍。连续真人镜头为人物一致性接受该成本；无人脸画外音只用音频引用。

## 长镜头策略

- 默认开启 13—24 秒长镜头，适合完整口播和低复杂度场景。
- 25—30 秒为边界区，只用于低台词密度、简单动作和稳定构图。
- 30 秒实测可用，但出现过同音字误识别，因此仍必须经过 BigASR 精确验收。

## 质量验收与重试

每条含台词母片必须通过 BigASR；每条母片还必须通过画面、人物、场景、动作、无人脸约束和“无可读文字”质检。台词、意外人物/文字或 QA 异常等硬缺陷可在预算内整条母片重生一次；单纯视觉语义偏差转人工复核。默认单次自动重试不超过 ¥8、标准版单 job 不超过 ¥25。通过验收后只做无新增模型费用的本地导演剪辑。

## TTS 与数字人

生产流已删除独立 TTS、音色目录、OmniHuman 和口型同步步骤。Seedance 2.5 原生音频是唯一对白来源；字幕仍在 FFmpeg 合成阶段统一烧录。

## BGM

| 来源 | 成本 | 说明 |
|---|---:|---|
| 本地音乐库 | ¥0 | 默认；放入 `references/bgm_library/<mood>/` |
| 无 BGM | ¥0 | 依赖 Seedance 原生人声、环境音和物件音 |

BGM 只在最终合成时以低音量混入，不得覆盖原生对白。
