## 硬约束(必须遵守)

1. **0-3 秒强钩子**:第 1 镜必须是冲突/反常识/数字/痛点
2. **分镜数量按时长定**:30s 约 5-6 个 / 18s 约 3-4 个 / 12s 约 2-3 个,**每个 dialogue 镜头 5-8 秒**,总时长接近 {{duration}} 秒
3. **强烈优先 dialogue 镜头** —— **每个镜头都是角色在场景里说话**
   - dialogue 镜头单段 ≤ 10 秒(OmniHuman 音频限制)
   - broll(纯空镜)**最多 1 个**,且只在以下情况使用:
     - 真正必要的数据/单据/特写过渡(如计算器特写、合同特写)
     - 不要用 broll 做"空镜过渡"——会割裂
   - 否则**全部 dialogue**:同一主角在不同场景说话,场景切换通过更换"角色所处场景"实现
4. **多角色**:必须 **2-3 个角色**,每个角色有清晰的 `look`(外观特征短描述)
5. **反转/喜剧结构**:setup(铺垫 60%) → twist(反转 25%) → tag(收尾 15%)
6. **避免 AI 翻车内容**:不要写"双手做精细动作""3 人同框对话""阅读书写"。
   - ⚠️ **文字/数字渲染规则**:现在出图用 gpt-image-2(默认),**价目表/合同/单据上的关键数字可以写出来**(反转更扎实,比如桌上价目表清晰可见「日租 800 / 月租 200」)。如果 `IMAGE_PROVIDER` 切回 `seedream`,要回避场景内文字
7. **dialogue 镜头每个必须有以下字段**(自检会逐项核对,缺一项画面就会退化成"面瘫念稿"):
   - `speaker`:谁说话(character id)
   - `shot_type`:景别 —— 近景 / 中近景 / 中景 / 远景(优先近景、中近景,才出得了表情)
   - `camera`:运镜 —— 写法见下方「dialogue 运镜写法」,**用"描述运镜结束状态"的方式写**(OmniHuman 官方技巧)
   - `lens`:焦段 + 景深,15-30 字(如「85mm,f/2.0 浅景深,背景奶油虚化」)
   - `lighting`:**该镜头独立的光线方案**,20-40 字 —— 光位 + 冷暖 + 对人物的塑形(如「侧逆光,窗光勾发丝肩线金边,面部一档柔光补暗部」)
   - `scene`:**角色所在的具体场景**,**40-80 字**,具体到家具 / 物件 / 远景
   - `scene_dynamics`:**场景微动态**,20-40 字 —— 让静帧"活"起来的细节:浮尘在光柱里飘、光影缓慢移动、风掀纸角、远景有人走动、蒸汽升腾、布料飘动等。**不要**写文字、精细手部、密集人群(会翻车)
   - `action`:**角色身体姿态 + 手势**,**30-60 字**(单手或上半身动作,避免双手精细动作)
   - `expression_arc`:**表情时间线**,按「起 → 中 → 末」三段写情绪在这 5-8 秒内的**变化**,不是一个静态表情(写法见下文)
   - `dramatic_keywords`:3-5 个情绪关键词,逗号分隔(如「怀疑, 精明算计, 不易察觉的得意」)
   - `emotion`:**配音情绪 token**(英文)—— 从该角色所选「多情感音色」的"支持情感"列里挑一个,如 angry / coldness / sad / hate / surprised / happy / excited。必须贴合本镜 `expression_arc` 的情绪;枚举较粗,挑最接近的(如"怀疑/不屑"→`hate`,"算计/冷静"→`neutral` 或 `coldness`,"惊愕"→`surprised`)
   - `emotion_scale`:配音情绪强度,整数 **1-5**(默认 4)。反转点/爆点镜头用 4-5;铺垫/平静镜头用 2-3
   - `voiceover`:**口语化台词**,**25-45 字第一人称**(中文约 5 字/秒,要撑满 5-8 秒镜头)。短了视频会被音频长度截断,达不到目标时长。可以加自然停顿、反问、感叹丰富节奏
   - `subtitle`:字幕,可与 voiceover 微调
8. **角色形象一致性 + look 字段写法(关键!)**:同一角色在不同 dialogue 镜头中,**外观必须用同样的 `look` 描述**(系统会用同一个 seed,但你的描述也要严格一致)。**Seedream 5.0 没有 reference image API,所以脸的稳定全靠 look 字段强约束**。规则:
   - ✅ **必须用"否定锚定"**:写明 `**绝非 X 型 / 必须 Y 型**`,锁死面相档位。例:`**面相北方汉子 / 老牌工程承包人,绝非小白脸 / 文艺青年 / 眼镜书生型**`
   - ✅ 关键特征用 **粗体** 强调:发型 / 脸型 / 眉眼 / 肤色 / 服装,Seedream 会优先尊重粗体内容
   - ✅ look 字段长度 **≥ 80 字**,覆盖:年龄 + 地域 + 发型 + 脸型 + 五官 + 肤色 + 气场 + 服装 + 反向约束
   - ❌ 不要写"普通中年男"、"年轻女白领"等笼统描述 —— Seedream 在不同 scene 里会解读成不同人

## render_mode —— 混合路线(控成本的关键)

每个 dialogue 镜头必须标 `render_mode`,决定走哪种视频生成:

| render_mode | 实现 | 成本 | 用在哪类镜头 |
|---|---|---|---|
| `digital_human` | OmniHuman 真人脸开口,嘴型同步 + 情绪表演 | 高(¥2-3/镜) | **情绪爆点**:反转瞬间、愣住/苦笑/暴怒、需要看脸的金句 |
| `scene` | Seedance 场景视频 + 配音作画外音(V.O.),不要求嘴型 | 低(¥0.5/镜) | **铺垫/揭秘/过渡**:讲事实、列数据、环境交代、动作展示 |

**分配原则(一条 30s 片典型)**:
- **2-3 个 digital_human**(钩子镜 + 反转镜 + 收尾金句)—— 把钱花在有表演价值的脸上
- **2-3 个 scene**(中间铺垫/揭秘)—— 画外音 + 场景画面 + 字幕,省一半成本
- 全 digital_human 是浪费;全 scene 没有真人感染力。**混合才是最优**

⚠️ `scene` 模式镜头:配音是**画外音/旁白**,所以 `action` 写"人物在场景里做什么动作"(不是"对镜头说话"),镜头可以是背影/侧面/远景/特写物件 —— 反正不露正脸开口。

## dialogue 运镜写法(`camera` 字段)

dialogue 镜头由音频驱动数字人(OmniHuman 1.5)生成。官方明确支持用提示词控制运镜——
**核心技巧:描述"运镜结束时的镜头状态",模型据此控制运镜快慢和落点;加"迅速""快速"等词能提高响应率**。

可用的运镜(单选或组合):

- `推 / 拉` —— 推近强调表情,拉远交代环境(写成「镜头从中景缓慢推近至面部特写」)
- `摇 / 移` —— 左右摇、平移(写成「镜头向右摇,聚焦到人物正脸」)
- `环绕` —— 轻度环绕增加立体感(写成「镜头向右环绕到人物正面」)
- `焦点变化` —— 前景虚→人物实,或人物→背景(配合场景里的物件/远景表意)
- `固定 + 呼吸感微晃` —— 最稳,适合反转点、情绪定格

写法范例:`镜头从侧面缓慢推进到正面中景` / `镜头焦点从前景图纸移到人物脸上`

⚠️ 剧烈甩镜、快速穿越镜头、航拍这类极端运镜,在人像驱动下不稳定 —— 留给 broll 镜头(Seedance 文生视频,运镜全可控)。

## expression_arc / dramatic_keywords 写法(对抗"面瘫"的关键)

OmniHuman 官方原话:**"结合音频内容描述细腻的情绪变化"**。情绪不是单点状态,是和台词同步推进的轨迹。三条铁律:

1. **写"变化"不写"状态"** —— 用官方句式「先是…… → 随后(突然)……」。一个镜头 5-8 秒是个过程。
   - ✅ `起·先是神情淡定地审视价目表 → 中·随后瞳孔微缩、嘴角下压、眉心收紧 → 末·鼻腔轻哼一声、缓缓靠回椅背`
   - ❌ `面带微笑` / `表情严肃`(静态单点 = 面瘫感的根源)
2. **用具体微表情词,不用抽象情绪名** —— 官方例句用的是:神情淡定 / 紧张惊慌 / 眉头紧皱 / 惊愕 / 陶醉 / 不可思议地 / 心情平静。**不要**写"开心""愤怒""难过"这种抽象词。
3. **`expression_arc` 和 `emotion` 必须一致** —— `expression_arc`/`dramatic_keywords` 控画面表情,`emotion`/`emotion_scale` 控配音情绪,两者是同一条情绪曲线,不能画面写"惊慌"而配音 `emotion` 填 `neutral`。

反转点镜头的 `expression_arc` 必须写出"愣住 → 恍然 / 苦笑 / 错愕"的转折瞬间。

## 剪辑节奏强约束(短视频灵魂)

短视频的"节奏感" ≠ 单镜长度,而是**切镜频次**。研究:抖音爆款平均 3-5 秒一切,视频号 4-6 秒一切,**单角色独白超 7 秒用户就划走**。

**强制规则**(高于其他时长建议):

1. **单 dialogue 镜头 ≤ 6 秒**(原 5-8 改 4-6,反转点镜可破例 7 秒)
2. **30s 片至少 6 个镜头**(切镜频次 5s/镜),不要为了凑时长拉单镜
3. **反转喜剧强制 A→B→A→B 切镜模式**——
   ❌ 错误:老周一个人讲 30 秒讲完全程(单人独白病)
   ✅ 正确:老周说一句(4-5s)→ 王工/老法师戳穿一句(4-5s)→ 老周愣(3-4s)→ 王工继续点拨(5s)→ 老周苦笑收尾(5s)
4. **单人长镜只在两处用**:
   - 第 1 镜 hook(主角抛悬念,6-7s 让观众进入)
   - 末镜告诫/收尾(主角对镜头总结,5-6s)
5. **中段反转必须双角色切换**——揭秘/戳穿/反应这三个动作分别在不同角色身上,每镜 ≤5s
6. **render_mode + 切镜配合**:
   - 反转爆点镜(脸戏)→ digital_human + 短镜 4-5s
   - 铺垫揭秘镜(说事实)→ scene + 短镜 4-5s
   - **不要**让一个 scene 镜 8 秒讲完所有信息——拆成 2 个 4 秒 scene 镜更好

**反例**(v2.3 之前常见):5 个 dialogue 镜全是老周一个人,每镜 6 秒 = 30 秒老周独白片。**这就是节奏拖沓的根源**,即使台词好也没人看完。

## 反转喜剧结构模板(必须遵循其一)

**A 认知差反转**:角色 A 一本正经讲常识 → 角色 B 一句话戳破
**B 反差打脸**:角色信誓旦旦做 X → 现实完全相反
**C 错位喜剧**:两角色对同件事理解完全不同,场面失控
**D 三段反转**:看似要 X → 反转成 Y → 再反转成 Z

## 反转必须基于真实行业逻辑(关键!)

**剧本要"有梗"必须有真实业务逻辑做反转支撑**。在写分镜前,先想:
1. 列 3 个该主题的**真实行业事实**(具体到数字/规则/隐藏成本/计费方式),记在 `reversal_research` 数组里
2. 从中选 1 个**最戏剧化、最有"卧槽!"反应**的,作为反转点
3. **不要瞎编**,事实必须经得起业内人士推敲

## 喜剧反转的质量评分(达不到这个标准就重写)

一个**有意思**的反转,必须满足下面**至少 2 条**:

| 要素 | 描述 | 例子 |
|---|---|---|
| **金额 stakes** | 反转涉及**具体金额数字**,且让人肉疼 | "200 真的,但违约金 10 万" |
| **反差强度** | 期待 vs 现实**反差极大**(便宜→坑/简单→复杂/省钱→倍杀) | "省 200/月 vs 实际多花 5000" |
| **可吐槽** | 听完想笑骂"这也叫便宜?""你大爷的" | "200 不是月租是诚意金" |
| **可恍然** | 揭示一个**业内人都不会主动告诉外行**的规则 | "押金 1.5 倍月租意味着..." |
| **多层翻转** | 表面 X,深一层是 Y,再深一层是 Z(三段式) | 看似便宜→其实贵→其实最贵 |

### ❌ 弱反转的典型 = 只输出"原来还有这事"的信息

- "原来月租 200 是预付折扣价,签约 6000"(只是教育,没情绪)
- "原来要交押金"(基础常识,不算反转)
- "原来有运输费"(说了等于没说,要给具体金额)

### ✅ 强反转的样板

- "200 是真的,但**违约金 5 万**,你试试退" → 金额 stakes + 可吐槽
- "200/月 你以为省钱?**送货费 800/趟,一个月 3 趟你就亏了**" → 反差 + 多层
- "200 是预付折扣,签约 30 天起,**外加押金 9000,先压一个月**" → 金额 stakes + 恍然
- "200/月 真的,**但必须租 3 年,违约金 18 万**" → 反差 + 金额 stakes

### 其他行业可类比的反转点结构

- 价格陷阱(单价 vs 总价 vs 隐藏费)

## 镜头结构最佳模板(30s 反转喜剧)

5 个 dialogue,主角在不同场景说话:

5. 主角 A 或 B 在结尾场景给评论钩子

- [ ] 分镜数匹配时长(30s≈5-6 / 18s≈3-4 / 12s≈2-3),**至少 80% 是 dialogue**(broll 最多 1 个)

- [ ] **`voice_directive` 写法**(实测 V3 极端版最适合 30s 短视频快速带情绪):**自然语言整段描述,60-100 字**,覆盖情绪 + 语气 + 语速 + 节奏 + 微动作(粗糙嘶哑 / 破音边缘 / 倒吸气 / 拍桌前 / 咬牙 / 叹气 / 上扬到尖)。**写得越具体到生理反应越对**——
