# Skill 分发更新验收

交付方式是 Skill 文件夹或 ZIP。配置、SQLite、人物素材和成片位于独立运行目录；使用方同步 Skill 后，由 Agent 执行自举。

## 交付与恢复条件

更新前关闭管理服务，保留位于目标目录外的新暂存包。分发器先复制完整包并检查必需入口和脱敏审计，再在运行时互斥锁下迁移旧状态、保留旧代码目录并切换新代码。复制和审计失败时旧目录不变；新目录提升失败时恢复旧目录。恢复也失败时，唯一旧副本与事务记录会留在目标父目录 `.skill-replacement-*` 中。

进程环境中 `FACTORY_RUNTIME_HOME`、`FACTORY_ENV_FILE`、`FACTORY_DATA_DIR` 或 `FACTORY_DB_PATH` 的绝对路径若指向目标 Skill 内部，分发器会在修改任何文件前拒绝替换。将运行状态迁移到外部稳定目录后重试。

更新进程在旧目录改名后硬退出时，目标 Skill 可能暂时不存在。重新执行原暂存包的分发器会在锁内恢复唯一已记录的旧目录，再继续更新。多个匹配记录不自动选择，保留证据并停止诊断。此机制不等同操作系统级双目录事务或任意磁盘损坏恢复；独立运行数据始终保留。新版自举成功前不要删除暂存包。

## 验收旅程

`tests/skill_delivery_journey.py` 从实际 Git 历史 `59556cf` 导出 `3.2.0.1`，使用该版本的分发和初始化代码构造旧任务。新增历史任务和媒体是明确的技术夹具，不读取正式任务数据。

| 路径 | 实际入口与检查 |
|---|---|
| 首次使用 | 创建无项目依赖的 Python venv，解压新 ZIP，运行包内 bootstrap，实际建立项目 venv 并从离线 wheelhouse 安装依赖；无凭证时返回配置缺失，learning 档位可就绪 |
| 管理服务 | 启动包内管理服务子进程，读取本地 HTTP；服务持锁期间更新返回运行时占用错误，原代码保留 |
| 历史升级 | 使用真实旧包的 `.env`、SQLite、成本账本、人物素材和可解码合成 MP4；从新暂存包执行更新，再运行新包自举；检查配置、媒体哈希、账本和路径迁移 |
| 历史续作 | 新包管理服务读取旧成片，经 HTTP 获取原媒体，并执行脚本化六项终审，任务从 COMPOSED 收敛到 READY_TO_PUBLISH |
| 重复替换 | 再次覆盖代码并自举，外部配置、任务终态和费用保留 |
| 升级失败 | 使用包内已安装依赖的 Python，在测试副本的数据库初始化边界注入配置、费用和人物素材修改，写入故障到达记录后抛错；正式安装器恢复快照，数据库完整性和原数据恢复；新服务可继续另一个历史任务的终审 |
| 更新器硬退出 | 只在测试子进程的目录改名完成后硬退出；旧目录与记录留存；重跑暂存包更新器并自举，旧任务终态与既有一条费用记录不变 |

单元门禁另覆盖复制失败、审计失败、切换/回滚失败、来源目标重叠、不完整来源、运行时互斥、目标内部的进程状态路径、多份中断记录和 ZIP 写入失败。

## 运行方式

准备依赖缓存时允许包管理器访问依赖源；它不调用视频供应商。使用 wheel 而非仅下载源码包，避免离线安装还需要构建工具。

```powershell
python -m pip wheel --wheel-dir <wheelhouse> -r scripts/requirements.txt
python tests/skill_update_release_gate.py
python tests/skill_delivery_journey.py --wheelhouse <wheelhouse> --work-root <新的隔离证据目录>
```

旅程使用 `PIP_NO_INDEX=1` 安装缓存包，清除宿主 Provider 凭证和运行路径覆盖；原始子进程日志、PID、逐项断言与 `report.json` 留在指定隔离目录。运行目录必须是新目录，不复用正式数据。常规门禁为离线单元回归；独立旅程需 Python、FFmpeg、已准备的 wheelhouse 和含历史提交的 Git 检出。

## 证据边界

本轮旅程在 Windows 宿主执行，证明本机干净 Python 运行环境与一个真实历史版本的直接 Skill 更新。系统 Python 和 FFmpeg 已存在；没有执行全新操作系统或 macOS/Linux 的现场验收。其他历史版本仍需单独样本。

HTTP 终审使用脚本化确认，历史媒体为合成夹具，验证任务和媒体可继续处理，不证明真实内容质量或重新生成的效果。Provider 账本没有新增付费生成记录。Python socket 护栏记录被保护入口的外部连接；数据库初始化子进程会重设 PYTHONPATH，因此该记录不构成操作系统级整个进程树的网络隔离证据。
